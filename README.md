# Minimal Blog Card

This project is a simple blog card created using HTML and CSS. It displays a blog image, category, title, short description, and author information in a clean and modern card layout.

## About the Project

The goal of this project was to practice building a responsive UI component and improve my frontend development skills. The design focuses on simplicity, readability, and proper spacing.

## Built With

- HTML5
- CSS3

## Features

- Clean and modern design
- Responsive layout
- Blog image section
- Category tag
- Title and description
- Author information

## What I Learned

While building this project, I improved my understanding of:

- HTML structure
- CSS styling
- Flexbox layout
- Spacing and alignment
- Responsive design concepts

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/C22UG111CAP099/vchallenges-minimal-blog-card.git
```

2. Open the project folder.

3. Run the `index.html` file in your browser.
